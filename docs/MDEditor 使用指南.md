# MDEditor 使用指南

**本工具由 AI 辅助生成**：零依赖单文件 Markdown 编辑器，左侧写作、右侧实时渲染，全程本地运行。

## 基础语法

支持 *斜体*、**加粗**、~~删除线~~、`行内代码`，以及 [链接](https://example.com)。

> 引用块：把「>」放在行首。引用内部同样支持**加粗**等行内语法。

## 列表与任务

本工具的无序列表标记有独立语义（详见文末「语法速查与本工具的特殊写法」）：

`+` 渲染**实心圆点**，`-` 渲染**空心圆圈**，样式跟标记符走、与缩进无关（缩进只决定嵌套层级）：

+ 实心点列表项（加号）
- 空心圈列表项（减号）
  - 嵌套子项（缩进决定层级，样式仍跟自己的标记符走）

1. 有序列表项一
+ 单行回车不断序
  - 单行回车不断序
2. 有序列表项二（编号接力：显示编号由渲染器决定，输入数字只是标记）

- [x] 已完成任务
- [ ] 待办任务

> 注意：`*` 不作列表标记（`*星号*` 是斜体、`**双星**` 是加粗），行首 `* 内容` 会按普通段落处理。

## 代码块

```python
print("hello markdown")
```

代码块会**按围栏语言自动高亮**（highlight.js 本地部署，36 种语言含 **R**、Python、JS/TS、SQL、Bash、Go、Rust、Java、C/C++/C# 等），并跟随编辑器明暗切换主题。

- **必须写语言名才会着色**：` ```python ` → 高亮；不写语言的围栏保持纯文本（避免把 ASCII 图、日志、配置误判成某种语言而乱涂色）。
- 鼠标移到代码块上，右上角出现「**复制**」按钮，一键复制该块代码（导出产物里不包含该按钮）。
- 图表围栏（`mermaid` / `dot` / `wavedrom` / `vega`）不参与代码高亮，它们走图表引擎。

## 脚注、提示块与其它新语法（v2.1.0）

### 脚注

正文写 `[^标签]`，文档任意处写 `[^标签]: 说明`：

```text
这是正文里的脚注引用[^a]，另一处也引用[^a]。

[^a]: 脚注说明写在文档任意位置，渲染时会自动归到文末脚注区。
```

- **编号按「引用首次出现顺序」**自动重排（与定义出现的先后无关），同一标签多次引用共用一个编号。
- 脚注区自动生成在文档末尾，带「↩」回跳锚点。
- **没写定义的 `[^x]` 原样保留**（不会被渲染成坏链接）。
- 定义可写多行：续行缩进 4 个空格；空行结束该定义。

### 提示块（Callout）

```text
> [!NOTE]
> 提醒内容

> [!WARNING] 自定义标题
> 带自定义标题的警示
```

五种类型：`NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION`（各有配色）。不写标题时以类型名作标题；普通引用块（`> 内容`）行为不变。

### 行内高亮与上下标

| 写法 | 效果 |
| --- | --- |
| `==重点==` | <mark>重点</mark>（高亮底色） |
| `x^2^` | 上标 |
| `H~2~O` | 下标 |

删除线 `~~删除~~` 优先于下标解析（`~~x~~` 不会被拆成两个下标）；行内代码段内的 `~`、`^`、`=` 不生效。

### 定义列表

```text
术语
: 定义说明
: 第二条定义
    定义的续行（缩进 4 空格）
```

### YAML front matter（文档元数据）

文档第一行写 `---` 起头，可写标题、作者等元数据：

```text
---
title: 我的文档标题
author: 张三
tags:
  - 笔记
  - 方法
---

# 正文从这里开始
```

- front matter **不进预览正文**；导出的 HTML 文档标题优先取 `title`。
- 支持极简 YAML 子集：嵌套 map、列表（`- 项`）、标量（字符串/数字/布尔/null）。
- **写坏了不影响正文**：未闭合、非法 YAML、`---` 不在首行 → 一律按普通内容渲染，一字不丢。
- 本轮 Word 导出（v2.2.0）会把 front matter 交给 pandoc 写成文档属性。

## 图表作图（四种，全部本地渲染、离线可用）

把代码块的语言标记写成对应引擎名，预览区会把它渲染成图，改左侧源码即实时重渲：

| 围栏                               | 引擎        | 擅长                   |
| -------------------------------- | --------- | -------------------- |
| ` ```mermaid `                   | Mermaid   | 流程图、时序图、状态机、甘特图、思维导图 |
| ` ```dot `（或 `graphviz` / `viz`） | Graphviz  | 复杂依赖拓扑，自动布局质量最高      |
| ` ```wavedrom `                  | WaveDrom  | 数字信号时序波形（协议握手、寄存器时序） |
| ` ```vega `                      | Vega-Lite | 数据图表（柱状、折线、散点等）      |

图表围栏同样支持**版面百分比宽度**：在语言标记后加 `{数字}`（如 ` ```mermaid {30} `），图宽 = 版面宽度的 30%、等比缩放，规矩与图片宽度参数完全一致（空格可省、`{150}` 钳到 100、非法值不生效且字面原样显示）；不带参数时维持默认行为（大图不超过版面宽，小图保持原始尺寸）。宽度参数只影响渲染，**不改任何源文件**。

```mermaid
    style G fill:#8a2f2f,color:#fff
```

## 图片

图片语法：`![说明](图片路径或网址)`。下面这张图放在**同名资源目录**里，用相对路径引用——**`.md` 与 `.assets/` 是一对，一起拷贝即可完整迁移**：

![内嵌示例图](MDEditor 使用指南.assets/内嵌示例图.png)

网络图片写法相同，把括号内换成 https:// 图片网址即可（需联网）。

**本地图片**：直接复制一张图，在编辑区按 `Ctrl+V` 粘贴即可——编辑器会自动把它存到**同名资源目录**，并插入正确的相对引用，无需手写路径：

```
你的文档.md
你的文档.assets/          ← 图片都自动归到这里
    └ 20261014_235812_3421.png
```

文档里的引用形如 `![](你的文档.assets/20261014_235812_3421.png)`，与图片实际存放位置一致，预览即可显示。

> 提示：`Ctrl+V` 前请先保存文档（无文件路径时无法确定资源目录）。`.md` 与 `.assets` 目录是一对，一起拷贝给别人即可完整打开。

### 图片宽度参数 {N}

在图片引用后加 `{数字}`，这张图的宽度就 = **版面宽度的 N%**，高度等比缩放。基准是**版面**而不是原图：两张原图大小不同的图，只要参数相同，显示宽度就相同。下面是同一张图两次——第一次不带参数（大图按版面 100% 显示），第二次 `{40}`（版面的 40%）：

![内嵌示例图](MDEditor 使用指南.assets/内嵌示例图.png)

![内嵌示例图 40%](MDEditor 使用指南.assets/内嵌示例图.png){40}

- 参数范围 1~100：`{150}` 按 100 处理；`{0}`、`{abc}` 等无效值不生效（后缀原样显示，便于发现笔误）
- 网络图片与本地图片写法相同
- 分页导出时同样相对**页面版心**生效；超长图先按参数定宽，再按调整后的实际高度切片续排，条带保持同一宽度
- **原始图片文件只读不写**：参数只决定渲染与排版尺寸，预览、导出、分页切片（切片产生的是缓存副本）均不修改原图
- 图表围栏（mermaid / dot / wavedrom / vega）支持同一参数：` ```mermaid {30} `，规矩与此处完全一致

## 排版（工具栏「排版」按钮）

- 每种元素（正文 / H1 / H2 / H3~H6 / 引用 / 列表 / 表格 / 代码）可分别设置**字体、字号、对齐**
- 对齐支持：默认 / 左 / **居中** / 右 / 两端
- 段落缩进按元素独立：**首行缩进**或**悬挂缩进**，字符数可调，随字号自动换算
- 列表档的「首行缩进」会让**整项（含编号/圆点）一起右移** N 字符（缩进的是列表项整体，不是只有文字）；「悬挂缩进」则是编号突出、文本对齐的经典悬挂样式
- 表格样式：三线表、表头底色、首列底色（颜色可选）

## 界面与设置（v2.3.0）

工具栏是**菜单栏**，5 个一级菜单 + 1 个「设置」按钮：

| 菜单 | 里面有什么 |
| --- | --- |
| **文件** | 新建 · 打开 · 保存 · 另存为 · 最近文件 / 内置文档 |
| **编辑** | 一级/二级标题 · 加粗·斜体·删除线 · 行内代码 · 引用块 · 无序/有序/任务列表 · 链接 · 表格 |
| **视图** | 分屏 · 预览跟随 · 主题（暗色/亮色） |
| **导出** | HTML · 打印（分页 HTML）· Word · PDF |
| **AI** | 润色选中文字 · RAG 润色 · AI 设置 |

点击菜单标签展开，展开状态下把鼠标移到别的标签会直接切换；按 `Esc` 或点别处收起。

「**设置**」按钮打开统一设置面板，五个页签：

- **外观**：主题、预览跟随
- **保存**：自动落盘间隔
- **排版**：正文/标题/引用/列表/表格/代码/公式的字体·字号·对齐，段落缩进，表格样式
- **分页**：纸张、页边距、页码（位置/模板/字号）、目录（位置/独占一页）——作用于「打印」与「导出 PDF」
- **外部工具**：pandoc、浏览器、Rscript、quarto 的探测结果，可「重新检测」

改完点「**应用**」。主题与跟随也能在「视图」菜单里快速切换，两处同步。

### 导出 Word / PDF 时的保存框

点「导出 → Word…」或「PDF…」会先弹**系统的「另存为」对话框**：默认文件名取自当前文档名，可以换目录、改文件名；目标已存在时会问是否替换。**点「取消」就什么都不做**，不会在别处偷偷生成文件。

## 保存与导出

- 编辑停顿即**存入浏览器缓存**，防丢稿
- 「设置 → 保存」里可设**自动落盘间隔**（0~60 分钟），到点自动写回原文件
- 「文件 → 保存」立即写回原 .md 文件（**尚未另存为的新文档，「保存」不可用，请先「另存为」**；只有「另存为」会弹出选择窗口）
- 打开文档时若含 base64 内嵌图或本机绝对路径图，保存/另存**会自动把图片收进同名 `.assets/` 并把引用改写为相对路径**
- 导出五件套：**.md**（纯文本）、**.html**（带排版与公式）、**打印**（纸张 / 页边距 / 页码 / 自动目录，Ctrl+P 直接出 PDF）、**Word**（`.docx`）、**PDF**（直接出文件）

### 导出 Word（.docx）

工具栏点「**Word**」，在文档同目录生成同名 `.docx`。

- **公式是 Word 原生公式**：写的 `$E=mc^2$` / `$$...$$` 会变成 Word 里可编辑的公式（OMML），不是图片也不是 LaTeX 源码。
- **脚注、定义列表、YAML front matter（标题/作者等元数据）、高亮、上下标**都按原结构进 Word；front matter 的 `title` 会成为文档标题属性。
- **Callout 提示块**在 Word 里呈现为**引用块 + 加粗类型名**（`> **NOTE**`）——Word 没有对应的容器样式，这是等价的表达。
- **图表围栏**（mermaid / dot / wavedrom / vega）在 Word 里是**代码块**（Word 不会渲染这些图）。
- 依赖**本机 pandoc**：没装时「Word」按钮置灰。安装：`winget install JohnMacFarlane.Pandoc`；已经装 Quarto / RStudio 的话，它们自带的 pandoc 会被自动识别。
- 未保存的新文档请先「另存为」——没有文件路径就不知道 Word 该放哪。

### 导出 PDF（直接出文件）

工具栏点「**PDF**」，在文档同目录生成同名 `.pdf`，**不弹打印对话框**。

- 纸张、页边距、页码、目录全部沿用「排版」面板里的分页设置，与「打印」一致。
- 依赖**本机 Edge 或 Chrome**（Windows 自带 Edge 即可）：没有时「PDF」按钮置灰。
- 生成前会核对「分页数 = PDF 页数」，不一致就**不生成文件**并提示改用「打印」——避免拿到半截文档。
- 与「打印」的分工：**需要书册级排版（页码、目录页码）并想自己检查打印预览 → 用「打印」**；**只想一键拿到 PDF 文件 → 用「PDF」**。

## 分屏滚动联动

在分屏（左编辑器 / 右预览）模式下，**滚动左侧编辑区，右侧预览会自动跟随**到对应位置——这是**单向**联动，预览滚动不会回牵编辑区。

联动以**标题为硬锚**：编辑区滚到某个标题附近时，预览精确锁定到该标题；两个标题之间按滚动百分比平滑过渡。因此哪怕文档里夹着一张几十行的大表格，预览也能连续扫过、不跳段、不丢行。

跟随行为可用工具栏「**跟随**」开关随时切换：开了预览跟随编辑区滚动，关了则两侧各滚各的。开关状态会记住，重启后保持。

## 选区批注

选中正文任意片段，浮动工具条点「**备注**」即可加批注，被标注文字以**虚线 + 淡底色**呈现。

批注**跟文本走，不跟位置走**：前后插入、增删段落，标注随文字移动不丢失；片段被删光时该批注自动失效。点正文里的虚线段，可随时查看、编辑、删除，或让 **AI 解释**该片段。批注随文档保存——普通文档存于 `<文档名>.assets/annotations.json`，`.smd` 存于包内，整理（compact）时一并保留。

## AI 润色

选中片段，浮动工具条点「**润色**」，AI 改写结果先弹出**原文 / 新文对照**预览（新文还能先手动微调），点「**替换原文**」才写回——绝不未经确认直接改动你的文字。

AI 解释（批注弹窗内一键按钮）可请 AI 解读当前标注片段。两者都要先配一个 LLM 后端：点「**AI → AI 设置…**」选后端、模型与参数。

| 后端 | 地址 | 说明 |
| --- | --- | --- |
| **LM Studio** | `http://localhost:1234` | 本地推理，默认项；需先加载模型 |
| **Ollama** | `http://localhost:11434` | 本地推理 |
| **DeepSeek API** | `https://api.deepseek.com/v1` | 云端；选后自动填地址，模型预设 `deepseek-chat`（通用）与 `deepseek-reasoner`（推理）；填 API Key 即可 |
| **OpenAI 兼容** | 自填 | OpenAI、硅基流动、OpenRouter 等同构端点，自填地址 + Key + 模型名 |

- 选 DeepSeek 时**不用手填地址**，模型下拉直接给出两个预设；`deepseek-reasoner` 不支持采样参数，工具已自动不发送 `temperature`。
- 本地后端的请求只发往你设置的本机地址，不经第三方；选择云端（DeepSeek / OpenAI 兼容）时，选中的文字会发往该服务，请自行判断内容是否适合外发。

## 语法速查与本工具的特殊写法

本工具**不是标准 Markdown 的照搬**，而是一套增强方言：标准语法之上加了一批自有写法，也有少数与社区惯例不同的地方。写文档时以下表为准：

### 与标准 Markdown 不同的地方

| 写法 | 本工具行为 | 标准社区惯例 |
| --- | --- | --- |
| `+` 无序列表 | 渲染**实心圆点** | 与 `-` 无区别 |
| `-` 无序列表 | 渲染**空心圆圈** | 与 `+` 无区别 |
| 无序标记与缩进的关系 | 样式跟标记符走，缩进只决定嵌套层级 | 空心圈通常是嵌套二级的默认外观 |
| `*` 星号 | 只作行内斜体 / 加粗，**不作列表标记**（行首 `* 内容` 按普通段落） | `* 内容` 是合法无序列表 |
| 有序列表编号 | **编号接力**：显示编号 = 渲染器按区域顺序生成，输入数字只是标记（写 `5.` 也按顺序显示） | 显示编号 = `<ol start>` + 逐项递增 |

### 本工具特有的写法

| 写法 | 作用 | 详见 |
| --- | --- | --- |
| `![说明](图片路径){30}` | 图片宽度 = 版面宽度的 30%、等比缩放（基准是版面不是原图，不改原图文件） | 「图片 · 图片宽度参数」 |
| ` ```mermaid {30} ` 等图表围栏带 `{N}` | 图表宽度 = 版面宽度的 N%，规矩与图片 `{N}` 完全一致（空格可省、钳制 100、非法字面保留） | 「图表作图」 |
| ` ```mermaid ` / ` ```dot ` / ` ```wavedrom ` / ` ```vega ` | 四种本地图表引擎围栏，离线渲染 | 「图表作图」 |
| `- [x]` / `- [ ]` | 任务列表（可勾选样式的待办项） | 「列表与任务」 |
| `~~文字~~` | 删除线 | 「基础语法」 |
| `$...$` / `$$...$$` | 行内 / 块级 LaTeX 公式 | 「数学公式」 |
| `[^标签]` + `[^标签]: 说明` | 脚注（编号按引用首次出现顺序，文末自动生成脚注区） | 「脚注、提示块与其它新语法」 |
| `> [!NOTE]` 等五型 | 提示块（NOTE / TIP / IMPORTANT / WARNING / CAUTION） | 「脚注、提示块与其它新语法」 |
| `==高亮==` / `^上标^` / `~下标~` | 行内高亮与上下标（`~~删除~~` 优先于下标） | 「脚注、提示块与其它新语法」 |
| `术语` + `: 定义` | 定义列表 | 「脚注、提示块与其它新语法」 |
| 文档首行 `---` 起的元数据块 | YAML front matter（不进正文，`title` 用作导出标题） | 「脚注、提示块与其它新语法」 |
| ` ```python ` 等围栏语言 | 代码语法高亮（36 语言含 R；不写语言则保持纯文本）+ 悬停「复制」 | 「代码块」 |

### 约定

- `\X`（X 为标点）：反斜杠转义，显示字面字符（防止标点被当作语法解析）；代码段内反斜杠保持字面
- 所有 `{N}` 类参数：数字为**版面百分比**，范围 1~100（超出钳到 100），非法值不生效且字面原样显示（便于发现笔误）
- 图表围栏内 `wavedrom` / `vega` 必须是**严格 JSON**（不支持 JS 对象字面量的裸键名）
- 原始文件（图片等）永远只读：任何参数与导出排版都**不修改文件本体**

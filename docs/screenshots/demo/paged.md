# 墨匠 MDWright 使用说明（节选）

这份文档用来演示分页导出：纸张、页边距、页码、自动目录都按「设置 → 分页」里的当前配置注入，导出的是**成品**，不是编辑器界面的截图。

## 页面与边距

纸张默认 A4，页边距上下左右各 2.54 cm，页码居中放在页脚。改动立刻反映到下一次导出。长表格与图片会按页切开，不会出现半行落在页脚的情况。

## 数学公式

行内公式 $E = mc^2$；块级公式：

$$
\hat{\beta} = \operatorname*{arg\,min}_{\beta} \sum_{i=1}^{n}\left(y_i - x_i^{\top}\beta\right)^2
$$

## 自动目录

打开「自动目录」后，标题层级收集成目录页，目录独占一页、不与其他正文挤在一起。目录与正文的页码对齐，右侧用点线连接。

## 导出的三种形态

| 形态 | 生成方式 | 典型用途 |
|---|---|---|
| 分页 HTML | Paged.js 组版 | 浏览器里 Ctrl+P 打印或存 PDF |
| PDF | 本机 Chromium 无头打印 | 直接交付 |
| Word（.docx） | pandoc 转换 | 交给需要改稿的人 |

## 离线依赖

KaTeX、Paged.js、Mermaid、Graphviz、Vega 全部随包内置，导出过程不联网。断网状态下从写作到导出成品，链路完整可用。

## 保存与版本

`.md` 是唯一事实来源，导出物随时可从它重建；`.smd` 把正文、图片、批注打包成单文件，换台机器打开要素齐全。
